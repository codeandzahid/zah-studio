# Video Studio

One repo with the prompts and guides used to make the videos.
Clone it on any computer — laptop or cloud — and use it anywhere.

## What's inside

| Folder | What it is |
|---|---|
| `prompts/video-prompts.md` | Ready prompts for realistic videos (jungle walk, jungle property series Ep 1). |
| `prompts/master-prompt-script-generation.txt` | 17-section prompt that turns a topic into a high-retention YouTube script. |
| `docs/zack-d-style.md` | The Zack D. Films 3D-simulation style guide (Blender + After Effects + Cascadeur + EmberGen). |

## Use it

- **Realistic videos:** 6 clips of 10 seconds from an AI video tool,
  each continuing from the previous clip's last frame, joined into
  60 seconds. Prompts stay short — long prompts fail. The exact
  prompts are in `prompts/video-prompts.md`.
- **Scripts:** feed a topic to the master prompt in
  `prompts/master-prompt-script-generation.txt` and get a full
  high-retention YouTube script back.
- **Style:** make finance videos in the Zack D. Films 3D-simulation
  style — see `docs/zack-d-style.md`. Show the idea in 3D, never flat
  bars, and put numbers on screen as clean overlays, never generated
  inside the animation.

## Offline?

The prompts and guides are plain text — they work anywhere, no
internet needed to read and use them. The AI video tool itself needs
an internet connection to generate clips.
